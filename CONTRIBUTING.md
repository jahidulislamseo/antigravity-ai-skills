# 🤝 Contributing to Antigravity AI Skills

Thank you for your interest in contributing! This project grows with community input.

## 🚀 Ways to Contribute

### 1. Add a New Skill
The easiest and most valuable contribution:

```bash
# Fork the repo, then:
git checkout -b skill/my-new-skill

# Create your skill directory
mkdir -p skills/my-new-skill

# Create the SKILL.md file (required)
touch skills/my-new-skill/SKILL.md
```

**SKILL.md minimum format:**
```markdown
---
name: my-new-skill
description: What this skill does and when to use it (2-3 sentences)
---

# Skill Name

## When to Use
...

## Instructions
...
```

### 2. Improve an Existing Skill
- Fix outdated information
- Add better examples
- Improve instructions clarity

### 3. Translate Skills (Great for non-native English speakers!)
- Create `skills/bn/skill-name/SKILL.md` for Bengali
- Any language welcome — see [Issue #5](https://github.com/jahidulislamseo/antigravity-ai-skills/issues/5)

### 4. Fix Bugs / Documentation
- Report via [Issues](https://github.com/jahidulislamseo/antigravity-ai-skills/issues)
- Fix typos, broken links, unclear steps

### 5. Add Windows Support
- See [Issue #1](https://github.com/jahidulislamseo/antigravity-ai-skills/issues/1)
- PowerShell install script needed

## 📋 Pull Request Process

1. **Fork** the repository
2. **Create a branch**: `git checkout -b feature/your-feature`
3. **Make your changes**
4. **Test locally**: Verify skill installs correctly
5. **Commit**: `git commit -m "✨ Add: your-skill-name skill"`
6. **Push**: `git push origin feature/your-feature`
7. **Open PR** with a clear description of what you added/changed

---

## 🏷️ Commit Message Convention

```
✨ Add: new-skill-name skill
🐛 Fix: broken link in content-writer skill
📝 Docs: improve installation instructions
🌍 i18n: add Bengali translation for gbp-optimization
⚡ Improve: fastapi-expert prompt quality
```
