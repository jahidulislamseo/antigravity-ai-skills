# Agency-Grade Visual Client Report Builder

Transforms raw local SEO audits, rankings, and analytics data into stunning, executive-ready HTML deliverables and print-perfect PDF reports that impress clients and close deals.

## Core Capabilities

1. **Executive Scorecards**: High-impact KPI widgets (Share of Local Voice, Total Calls, Review Velocity, Map Pack Health).
2. **Interactive Geogrid Heatmap Visualization**: Visual 3x3 or 5x5 grid representing local rank drop-off by distance (Green #1-3, Yellow #4-10, Red #10+).
3. **Head-to-Head Competitor Radar**: Side-by-side comparison tables against top local 3-pack competitors.
4. **Actionable 30-60-90 Day Strategy Roadmap**: Clean phased action plan with estimated business impact.
5. **Print-to-PDF Design**: Embedded print CSS (@media print) so saving to PDF produces a flawless, multi-page branded agency document without URL headers or cut-off widgets.

## Report Standards

- **Typography**: Modern Google Fonts (Outfit, Inter, or Plus Jakarta Sans).
- **Color Palette**: Sophisticated agency styling (Deep slate navy #0f172a, crisp emerald #10b981 for wins, warm amber #f59e0b for warnings, crimson #ef4444 for gaps).
- **Format**: Self-contained HTML file (CSS & SVGs inlined) that opens in any browser, works offline, and prints directly to PDF.
- **Tone**: Business-oriented, translation of technical metrics into patient calls, inquiries, and revenue.
