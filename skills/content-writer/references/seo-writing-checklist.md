# SEO Writing Checklist, Anti-AI Slop Standards & Content Template

Compact checklist for drafting SEO content that is useful, scannable, human-sounding, and ready for a CORE-EEAT review.

## On-Page & Anti-AI Checklist

| Area | Required checks |
|------|-----------------|
| Keyword placement | Primary keyword in title, H1, first 100 words, at least one H2, and meta description; secondary terms in H2/H3s; related entities throughout body. No stuffing. |
| Search intent | Direct Answer Block in the first 75-100 words without throat-clearing intro. Mixed-intent pages answer the primary intent first. |
| Quality & Mechanism | Never state an outcome without the operational/physical mechanism (exact materials, standards, tools, codes, or formulas). |
| Cadence Asymmetry | Mix punchy 4-word sentences with 20+ word analytical breakdowns. Avoid uniform-length paragraphs. |
| Forbidden AI Syntax | Zero instances of "not only X, but also Y"; zero adjective triplets ("innovative, scalable, and secure"); em-dashes capped at ≤ 2. |
| Lexicon Filtering | Zero occurrences of banned AI marker words (`delve`, `tapestry`, `pivotal`, `paramount`, `crucial`, `elevate`, `seamless`, `effortlessly`, `multifaceted`, `transformative`). |
| Technical | 2-5 relevant internal links with descriptive anchors, 2-3 authoritative external links tied to specific claims. |
| Snippet targeting | Definition answers in 40-60 words, ordered steps for how-to queries, structured tables for comparisons. |

## Copy-Start Template (Anti-Slop Structure)

```markdown
# [H1 with Primary Keyword: Specific Angle/Scope]

**Meta Description**: [145-155 char value proposition with primary entity and practical CTA]

[Direct Answer Block: 2-3 sentences answering primary query immediately with concrete metrics/standards. Primary keyword naturally integrated without throat-clearing.]

## [H2 with Operational Scope / How It Works]
[1-2 sentence setup explaining the practical mechanism]
[Analytical breakdown with evidence, specific tools/materials, or code compliance]

### [H3 for Sub-Component]
- [Actionable point with specific metric/tool]
- [Actionable point with specific metric/tool]

## [H2 for Technical Comparison / Specifications]
> **Operational Note**: [Specific, non-obvious practical requirement or trade-off]

| Dimension | Option A | Option B | Standard / Source |
|---|---|---|---|
| [Parameter] | [Evidence] | [Evidence] | [ASTM / ISO / Official standard] |

## Frequently Asked Questions

### [Practical question from PAA or common buyer query]?
[Direct 40-60 word answer answering the mechanism first, followed by one real-world caveat.]

## Next Operational Steps & Considerations
[Immediate actionable next steps, cost drivers, or verification checklist. DO NOT write a repetitive summary or "In conclusion" recap.]

**Sources & Standards**: [Standard/Source name + Official reference + Verification date]
```

## Snippet Patterns

| Snippet type | Pattern |
|--------------|---------|
| Definition | `[Term] is [clear definition]. It operates by [mechanism].` Keep to 40-60 words. |
| List | Introduce the list under an H2, then use numbered or bulleted items with parallel phrasing. |
| Table | Use simple headers and one idea per cell; avoid over-wide tables on mobile. |
| How-to | Label each action `Step 1`, `Step 2`, and include prerequisites before the steps. |
| FAQ | Answer directly first, then add nuance or operational caveats in the next sentence. |

## Wikipedia Signs of AI Self-Audit Checklist

Before submitting or publishing any draft, run these 7 mandatory gates:
- [ ] **Direct Answer**: Does the first 100 words answer the searcher's core question without fluff?
- [ ] **Negative Parallelism**: Are all "not only X, but also Y" constructions removed?
- [ ] **Rule of Three**: Are all 3-adjective lists reduced to 1 precise descriptor or quantitative metric?
- [ ] **Em-Dash Limit**: Are there 2 or fewer em-dashes across the entire piece?
- [ ] **Lexicon Scrub**: Are words like `delve`, `pivotal`, `tapestry`, `elevate`, and `seamless` completely eliminated?
- [ ] **Evidence & Mechanism**: Does every major benefit claim name the physical/operational mechanism?
- [ ] **Repetitive Conclusion**: Did you avoid summarizing what was already said? Is the ending practical and forward-looking?
