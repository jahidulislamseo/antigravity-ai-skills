## ⚡ 1-Click Fast Install (Mac & Linux)

On any computer where you want to install this entire AI Operating System, open the terminal and run:

```bash
git clone https://github.com/jahidulislamseo/antigravity-ai-skills.git && cd antigravity-ai-skills && ./install.sh
```

That's it! All **126 skills** and **permanent system rules** will be automatically copied into your global configuration (`~/.gemini/config/`).

## 🧠 Core System Directives: The 3-Step Execution Protocol

Whenever you give an instruction to the AI agent, it strictly executes this workflow:

1. **STEP 1: 10-Year Senior Expert Prompt Generation**
   - Automatically formulates a battle-tested master prompt following the **ROCS-EO & Zero-Assumption** standard before touching code or audits.
2. **STEP 2: Skill-Based Deep Execution**
   - Autonomously selects and chains the required specialized skills to produce concrete, high-rigor fixes.
3. **STEP 3: Report Gating**
   - Strictly withholds unsolicited long audit decks or reports unless explicitly requested by the user.
